# 01. Project Overview

## Student Management System

The **Student Management System** is a full-stack CRUD web application developed as a college mini-project. It enables administrators and faculty to create, view, update, search, filter, and delete student records cleanly and securely.

### Scope & Constraints
- **Strict Scope**: Focused exclusively on Student record management (Student ID, Name, Email, Department, Year, Phone).
- **No Pre-populated Data**: Starts with 0 database records. All records are created manually through the application or API.
- **Persistence**: Powered by a Python Django REST Framework backend with an SQLite database.
- **User Interface**: Clean, responsive glassmorphic React user interface.
