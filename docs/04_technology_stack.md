# 04. Technology Stack

### Frontend
- **React (18+)**: Component-based UI library initialized via Vite.
- **JavaScript (ES6+)**: Frontend application logic and state management.
- **HTML5**: Semantic document structure.
- **Vanilla CSS3**: Custom responsive design system with CSS Grid, Flexbox, glassmorphism, and keyframe animations.

### Backend
- **Python (3.10+)**: Server programming environment.
- **Django (5.x)**: High-level Python Web framework.
- **Django REST Framework (DRF)**: Toolkit for building robust REST APIs with serializers and ViewSets.
- **django-cors-headers**: Middleware for handling Cross-Origin Resource Sharing (CORS) with React frontend.

### Database
- **SQLite3**: Lightweight, zero-configuration relational database engine managed via Django ORM.

### Testing & Tools
- **Postman**: API testing suite and collection.
- **Git / GitHub**: Version control system.
