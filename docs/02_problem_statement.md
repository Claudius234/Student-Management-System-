# 02. Problem Statement

Educational institutions frequently struggle with manual student record keeping or overly complex enterprise software that includes unnecessary modules (such as HR, billing, attendance, and hospital tracking).

### Problem Definition
1. **Inefficient Data Tracking**: Paper-based or spreadsheet-based records lead to data loss and duplicates.
2. **Bloated Software**: Standard management systems are bloated with irrelevant features.
3. **Lack of Validation**: Input errors such as duplicate Student IDs or invalid email formats compromise database integrity.
4. **Poor Responsiveness**: Legacy interfaces fail to work properly across modern laptops, tablets, and mobile devices.

### Proposed Solution
A lightweight, fast, full-stack Student Management System designed specifically to handle student CRUD operations with strict field validation, zero default sample data clutter, and dynamic search and filter capabilities.
